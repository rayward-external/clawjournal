Share original and redacted conversations?

Originals may contain personal information. This permission is separate from sharing edited snippets or normal redacted uploads. It is optional and starts off.

This covers future conversations captured into this local evaluation store after enabling. Both full normalized conversations—not only labelled snippets—can be sent. Only authorized administrators at the selected service can download these pairs. Hosted copies expire after 30 days. Downloaded research copies must remain access-restricted, follow the same purpose restriction and be deleted within that period.

Originals containing possible credentials are blocked by local scanning. Automatic scanners can miss other private information. Labels remain drafts unless separately reviewed. Permission does not mean every label is correct.



Opening this page or downloading the permission file does not enable uploads. Import the permission file first. Each upload is a separate command. Turning this permission off stops future exports/uploads and removes managed local pair bundles. It cannot recall downloaded copies; use the hosted withdrawal command for already uploaded pairs.


clawjournal redaction-eval --store YOUR_STORE pairs disable
